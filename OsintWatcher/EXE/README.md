## Installation

To use Ostium Osint Watcher with Ostium Osint Browser (integrating it into the tools menu), download and extract the ZIP archive to a location of your choice, then specify the path to OsintWatcher.exe in the Ostium Osint Browser settings. The Osint Watcher menu button will then become active.
